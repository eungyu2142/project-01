# 특수 동물 병원 필터링 및 지도 기반 리뷰 웹앱

특수 동물을 키우는 보호자가 주변 동물병원을 더 쉽게 찾고, 실제 진료 경험을 리뷰로 공유할 수 있도록 만든 지도 기반 웹앱입니다. 파충류, 설치류, 조류 등 일반 반려동물보다 병원 정보를 찾기 어려운 동물군을 기준으로 병원을 필터링하고, 현재 위치를 중심으로 가까운 병원을 확인할 수 있습니다.

병원 탐색에서 끝나는 것이 아니라 반려동물 관리, 진료 기록 작성, 리뷰 작성까지 한 흐름으로 연결합니다. 보호자는 등록한 반려동물별로 진료 기록을 모아볼 수 있고, 녹음 또는 음성 파일 업로드를 통해 수의사 의견을 항목별로 요약한 뒤 진료 기록 초안으로 활용할 수 있습니다.

## 주요 기능

- 현재 위치 기반 특수 동물 병원 지도 표시
- 파충류, 설치류, 조류 등 동물 종류별 병원 필터링
- 병원명 및 주소 검색
- 병원별 리뷰 조회 및 작성
- 최근 진료 동물 정보 확인
- 관심 병원 저장
- 반려동물 프로필 등록, 수정, 삭제
- 반려동물 분류별 프로필 및 진료 기록 필터링
- 진료 기록 직접 작성 및 임시 저장
- 녹음 또는 음성 파일 업로드 기반 수의사 의견 요약
- 진료 기록을 리뷰로 연결해 작성

## 프로젝트 목적

특수 동물 보호자는 진료 가능한 병원을 찾기 어렵고, 병원마다 실제로 어떤 동물을 진료했는지 확인하기도 쉽지 않습니다. 이 웹앱은 병원 위치 정보와 사용자 리뷰를 함께 제공해 보호자가 더 빠르고 신뢰할 수 있게 병원을 선택할 수 있도록 돕는 것을 목표로 합니다.

또한 진료 후 흩어지기 쉬운 처방, 진단, 주의사항, 방문 계획을 반려동물별 기록으로 남길 수 있게 하여 장기적인 건강 관리와 병원 선택 경험을 함께 개선합니다.
